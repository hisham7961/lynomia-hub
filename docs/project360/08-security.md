# الأمن (08)

تفويضٌ خادميُّ الحسم — لا تفويضٌ بالتجميع (§48):

- **العميلُ:** لا يبلغ قسمَ الأصول/المشاريعِ ولا مساراتِه (٤٠٤ ويباً وAPI · §86).
- **IDOR الشركات:** الأصلُ والمشروعُ يُحلّان بـ`hub_scope` → ٤٠٤ خارجَ النطاق (لا كشفَ وجود). والخدمةُ ترفض شركتين مختلفتين ٤٢٢. **cross-company leaks = 0** (مُختبَر).
- **الصلاحية:** `hub_can('assets','e')`+`hub_can('projects','v')` لكلِّ تغيير — المشاهدُ (view فقط) ٤٠٣.
- **الإنهاء:** يُحلُّ الأصلُ والمشروعُ ضمنَ النطاقِ قبل الإنهاء (لا إنهاءٌ لِما لا يُرى).
- **عضويّةُ المشروعِ لا تتجاوز** `hub_can`/العزل (§49).
- **حافّةُ الرسم:** كلُّ طرفٍ عبر `hub_read` — لا تسريبَ حافّةٍ لطرفٍ غيرِ مرئيّ (مُختبَر).
- **العدّاداتُ آمنة:** تُحسب على نفسِ النطاقِ المصرَّح (لا «١٠ ثمّ إخفاء ٣» · §69).
- **التدقيق:** كلُّ إنشاء/إنهاءٍ مُدقَّق (فاعل/أصل/مشروع/زمن/سبب) بلا أسرار (§47).
