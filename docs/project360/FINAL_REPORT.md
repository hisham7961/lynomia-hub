## ٣) القدرةُ الجديدة — تخصيصُ الأصلِ للمشروع

- **`asset_project_assignments`** (علاقةٌ زمنيّة) + `AssetProjectAssignment` + **`AssetProjectService`** (محرّكٌ واحد: إنشاء/إنهاء · idempotent · معاملة+قفل · تدقيق).
- **مستقلٌّ عن العهدة:** لا يمسّ الحائزَ/المحطّةَ/`asset_custody`/النقطةَ/الحالة؛ والإنهاءُ لا يفكّها.
- **فرادةُ النشط عبر المحرّكين:** فهرسٌ فريد `(asset_id,project_id,active_flag)` — NULL مختلفٌ في SQLite وMySQL.
- **متعدّد:** أصلٌ يدعم عدّةَ مشاريعَ نشطة؛ **التاريخُ محفوظ** (لا حذف).
- متحكّم ويب + API (`/api/v1/projects/{id}/assets`, `/assets/{id}/projects`, `/asset-project/{id}/end`) — بخدمةٍ واحدة (§56).
- **قسمُ الأصول** في المشروع 360 + **قسمُ المشاريع + التاريخ** في تفصيلِ الأصل (منتقٍ صالحٌ مُعادُ استعماله · §64).
- **حافّةُ الأصل↔المشروع** في المستكشفِ القائم (مصرَّحةُ الطرفين · §40).
- **سجلُّ القدرات:** `assets.project_assignment` من DEFERRED → **ENABLED** (صادق · §51/§87).
