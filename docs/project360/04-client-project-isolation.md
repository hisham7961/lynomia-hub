# عزل المشروع الداخلي عن العميل (04)

- **جمهورٌ صارم:** `Project::isExternal()` = `client_id!==null || audience==='client'`. الداخليُّ والعميلُ سطحان مختلفان (§13).
- **العميلُ يرى «النظرة» الآمنة وحدَها** في المشروع 360 (`hub_is_client` → تبويبٌ واحد)، ولا يرى: التكلفة/الميزانية/الهامش، البنيةَ (url/staging/git)، الغرفةَ الداخليّة، ولا **قسمَ الأصولِ ولا عدَّها** (§12/§70).
- قسمُ الأصولِ ومشاريعُ الأصلِ **داخلَ `@unless($isCli)`** — لا يُرسَل للعميلِ مطلقاً (لا عدَّ ولا صفوف).
- مساراتُ التخصيص/الإنهاءِ (ويب وAPI) تردّ للعميلِ **٤٠٤** (PortalGuard + abort).
- بوّابةُ العميلِ تبقى عبر `ClientPortalData` (أعمدةٌ عميليّةٌ فقط، fail-closed) — لم تُمَسّ.
- الغرفتان منفصلتان فيزيائيّاً (لا علامةُ رسالة) — الداخليّةُ للفريقِ فقط، وغرفةُ العميلِ يراها في بوّابته.
