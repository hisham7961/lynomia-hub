# السياق التقني والمالي (06)

## التقني
الخوادمُ/النطاقاتُ/قواعدُ البيانات/الهواتف ترتبط بالمشروعِ بعمود `project_id` حقيقيّ، وتظهر
**أبناءً** في `hub_related` (تبويب التسليم · `record_list`) — روابطُ معايناتٍ لشاشاتها القانونيّة (§77). **لا ربطٍ نصّيٍّ مُخمَّن** (§31). الأصولُ سياقٌ تقنيٌّ جديدٌ عبر التخصيص.

## المالي
`hub_project_pl` (P&L القائم) للداخليِّ المخوَّل فقط (`cost`+`budget` مرئيّان) — إيراد/تكلفة/ربح/هامش/ميزانية.
**لا دفترَ ثانٍ، ولا إعادةَ حساب، ولا كشفٍ للعميل** (§35). الحقولُ تُحرَس بـ`hub_field_mode`.

## المخرجات (Deliverables)
**لا دومينَ حقيقيّ** — لا جدولَ ولا نموذج، فقط حقلُ نصٍّ حرٍّ `deliverables` على وحدة `services`. **يُوثَّق بصدق، لا يُختلَق** (§30).
