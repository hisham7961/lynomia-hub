# تكامل التعاون (05)

- **التعاونُ يبقى المرجع** (`/collab` + غرفُ المشروع) — لا يُعاد بناؤه.
- تبويبُ «الغرف» (للمشروعِ الخارجيّ) يعرض الغرفتين ويضيف زرَّ **«افتح في مركز التواصل»** لكلٍّ (`collab.center?c=<room>` · §37) — دخولٌ للسطحِ الموحّدِ لا صفحةٍ قديمة.
- الغرفتان من `ConversationController::ensureProjectRooms` (idempotent) — لا تُعاد التهيئةُ بمجرّدِ فتحِ 360.
- لا استعلامَ تواريخَ رسائلَ كاملةٍ عند تحميلِ 360؛ لا تسريبَ محتوى عبر حدودِ الجمهور (§38).
