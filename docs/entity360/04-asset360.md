# ٠٤ — الأصل 360 (§28–39)

قشرةُ تبويباتٍ على `modules/custom/assets.blade.php`، يغذّيها `App\Support\Asset360`، بفصلٍ صريحٍ
**الحائز ≠ المحطة ≠ تخصيصُ المشروع** (§30). `assets` مُضافةٌ إلى `@unless` في `show.blade.php`.

## التبويبات

| التبويب | المحتوى | المصدر |
|---|---|---|
| النظرة | نظرةُ عدّادات (الحائز/المحطة/المشاريع/النقطة/الجرد/الحالة) · البيانات | `Asset360::overview` |
| العهدة | `custody_card` (الحائز + الحالة + التصاريح + السجلّ) (§30/§31) | `App\Support\Custody` |
| المحطة | المحطةُ الحاليّة (§32) + **تاريخُ الوضع** (§33) | `assets.station_id` · `asset_custody.station_id` |
| المشاريع | `asset_projects` — تخصيصٌ لا عهدة (§34) | `AssetProjectService` |
| التقنية | النقطةُ الطرفيّةُ الآمنة (§35) + الهويّةُ الموحّدة (§37) | `Asset::activeEndpoint` · `Identity` |
| الجرد | آخرُ مسحٍ وحُكم (§36) | `inventory_scans/items.asset_id` |
| الدورة | ضمانٌ/صيانةٌ/إخراجٌ + إهلاكٌ خطّيّ + تكلفةُ الملكية (§38) | حقولُ الأصلِ + `asset_maintenance` |
| النشاط | الملفُّ + الأبناءُ + الخطُّ الزمنيّ + النقاش (§39) | القرّاءُ العامّون |

## قراراتٌ صريحة

- **الحقولُ المقفولة** (`holder_id`/`station_id`/`status`) قراءةٌ فقط في 360 — الكتابةُ عبرَ `Custody`/`AssetProjectService`.
- **العهدةُ ليست تخصيصَ مشروع** — تبويبان منفصلان، وبيانٌ صريحٌ في كليهما.
- **الأهليّةُ صادقة:** غيرُ المؤهّلِ لنقطةٍ يُقال سببُه (`endpointIneligibleReason`).
- **النقطةُ آمنة:** لا `public_key`/`hw`/`posture` — `os/status/آخر نبضة` فقط.
- عزلُ العميل: `assets` خارجُ قائمة `PortalGuard` → **٤٠٤**.
