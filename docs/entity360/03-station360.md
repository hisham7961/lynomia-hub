# ٠٣ — المحطة 360 (§19–27)

قشرةُ تبويباتٍ (نمطُ المشروع 360) على `modules/custom/stations.blade.php`، يغذّيها `App\Support\Station360`.
`stations` مُضافةٌ إلى `@unless` في `show.blade.php` فتملك القشرةُ الجسدَ (لا تكرار).

## التبويبات

| التبويب | المحتوى | المصدر |
|---|---|---|
| النظرة | هويّةٌ+QR · نظرةُ عدّادات · البيانات | `code`/`Qr` · `Station360::overview` |
| الأشخاص | الشاغلُ الحاليّ (§20) + نماذجُ الإسناد/الإخلاء + التاريخ (§21) | `current_employee_id` · `station_assignments` |
| الأصول | الأصولُ الحاليّة (§22) + تاريخُ الوضع (§23) | `assets.station_id` · `asset_custody.station_id` |
| النقاط | الأجهزةُ الطرفيّةُ الآمنة (§24) | `endpoint_devices.station_id` (شراكةُ المحطة لا تمنح إدارةَ النقاط) |
| الجرد | آخرُ فحصٍ ونسبةُ المسح (§25) | مشتقٌّ عبرَ أصولِ المحطة (لا `station_id` على الجرد) |
| المشروع | مباشرٌ + **مشتقٌّ موسوم** (§27) | `stations.project_id` + (محطة→أصل→تخصيص) |
| النشاط | الملفُّ + الأبناءُ + الخطُّ الزمنيّ + النقاش | `dossier`/`record_list`/`timeline`/`comments` |

## قراراتٌ صريحة

- **الكتابةُ تبقى في `StationController` المقفل** (إسناد/إخلاء) — القشرةُ قراءةٌ فوقَه.
- **الشاغلُ واحدٌ** (`current_employee_id` عمودٌ مفرد) — العرضُ يعكس النموذجَ لا يفترضه.
- **المشروعُ المشتقُّ موسومٌ «مشتقٌّ لا مباشر»** فلا يُخلَط بإسنادٍ مباشر (§27).
- **الجردُ صادق:** لا رابطَ محطةٍ مباشرٌ — يُشتقُّ عبرَ الأصول، ويُقال.
- عزلُ العميل: `stations` خارجُ قائمة `PortalGuard` → **٤٠٤** للعميل.
