# ٠٦ — العروضُ المركّزة والعدسات (§46–49/§54/§56)

**عروضٌ فوق المحرّك الواحد** لا محرّكٌ ثانٍ: الجذرُ هو التركيز، والعدساتُ معاملاتٌ فوقَه.

## السياقاتُ المركّزة (§46)

كلُّ صفحة 360 تفتح جذرَها في المستكشف عبرَ زرِّ «العلاقات»؛ ووحدةُ الجذرِ تُسمّى سياقَها:

| الجذر | السياق |
|---|---|
| `hr` | 👤 سياقُ الموظف (محطة/أصول/نقطة/SIM/مشاريع) |
| `stations` | 🪑 سياقُ المحطة (موظف/أصول/نقاط/مشروع) |
| `assets` | 💻 سياقُ الأصل (حائز/محطة/مشاريع/نقطة/جرد) |
| `projects` | 🗂️ سياقُ المشروع التقنيّ (أصول/خوادم/دومين/قواعد) |
| `clients` | 🤝 سياقُ تسليم العميل |

(في `RelationshipExplorerController::FOCUS`.)

## العدسات (معاملاتٌ على `graph.explore`)

- **العمق** `hops=1..max_hops` (قائم).
- **وضعُ التاريخ** `history=1` (§54/§100): يُدرِج التخصيصاتِ المُنهاةَ موسومةً «تاريخيّة» (`active=false`) — لا تُوسَّع، ولا خلطَ بلا وسم. زرٌّ «🕰️ التاريخ».
- **المباشرُ فقط** `direct=1` (§47/§49): يُخفي الحوافَّ المشتقّة — عرضٌ لا حجبُ أمن (المشتقّةُ مصرَّحةُ الطرفين أصلاً). زرٌّ «↳ مباشرٌ فقط».
- **تحديث** `fresh=1` · **العروضُ المحفوظة** `SavedView` (قائم).

كلُّ العدساتِ تُحفَظ عبرَ أزرارِ العمق (لا تُفقَد بالتنقّل).

## التنقّلُ من العقدة (§55/§56)

كلُّ عقدةٍ تفتح سطحَها 360 القانونيّ: `hr → portal.employee`، وسائرُها `m.show` (وهو نفسُه 360
للمحطة/الأصل/المشروع). العقدةُ المشتقّةُ/التاريخيّةُ موسومةٌ ببادجٍ في الشجرة. لا سطحَ مسدود.
