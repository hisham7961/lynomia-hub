# خريطة اعتماديات نظام العمليات الميدانية (المندوب الطبي)

> ناتجُ التدقيق المعماري الإلزامي قبل أول سطر كود — v2.365.0.
> القاعدة الحاكمة: **امتدادٌ للقائم لا نظامٌ موازٍ**، ولا كسرَ لأي عقدٍ قائم.

## 1) ما وجده التدقيق (الركائز القائمة التي يُبنى عليها)

| الحاجة الميدانية | الركيزة القائمة | القرار |
|---|---|---|
| ملف المندوب | وحدة `hr` (جدول `employees`) + جسر `Workday::emp()` | **حقل «الدور الميداني» على ملف الموظف** — لا وحدة مندوبين موازية |
| حضور اليوم الميداني | محرك `Workday` بوضع «عمل ميداني» القائم وحالته | جلسة اليوم الميداني تُبنى **فوق** `checkIn/checkOut` لا بجانبه |
| التقرير اليومي | وحدة `updates` (بنود تغذي `tasks.act_h`) | تقرير الزيارة بندٌ مهيكل يرتبط بالزيارة — لا جدول تقارير ثانٍ |
| المنتجات المعروضة | سجل المنتجات `products` + سجل الهوية | العرض الطبي (detailing) يشير لسجل المنتجات القائم |
| العينات | العهدة `asset_custody` (حركة مؤرَّخة بحالة واستحقاق وسياق مشروع/عميل) | صرف العينات حركةُ عهدة بسياقها — لا مخزون موازٍ |
| سياق العميل | طبقة الارتباطات `engagements` + `hub_client_scope` | المنشآت والزيارات تحمل `client_id` فتكسب العزل مجاناً |
| التنبيهات والأتمتة | `hub.events` الدلالية + `rules` (عوامل «أيام متبقية/مضت») | أحداث `visit.*` و`cycle.*` تُضاف للخريطة الدلالية |
| API الجوال | `ApiAuth` + بروتوكول idempotency الناضج + قالب `metricsIngest` الدفعي | استيعاب نقاط GPS يقلّد `metricsIngest`: تحقق مسبق، سقف عدّ، معاملة واحدة |
| العمل الخلفي | نمط outbox بمطالبة ذرّية (لا طوابير — `QUEUE_CONNECTION=sync`) | معالجة المسارات المؤجلة أمرٌ مجدول كل ٥ دقائق بنمط المطالبة |

## 2) الفجوات المكتشفة (تُبنى لأول مرة)

1. **لا أعمدة إحداثيات ولا دوال مسافات في المشروع كله** — أول `lat/lng` حقيقية تدخل مع المنشآت، وأول Haversine مع النطاق الجغرافي.
2. **`Permissions-Policy: geolocation=()` يحجب الموقع كلياً** حتى عن التقاط الحضور القائم (يفشل بصمت). الحل في مرحلة GPS: سماحٌ **مضيَّق** لا فتحٌ عام، مع اختبار يثبّت الترويسة (لا اختبار عليها اليوم).
3. **لا `client_operation_id` في أي مكان** — منع تكرار نقاط GPS عند إعادة الإرسال يحتاج قيداً فريداً لكل عملية عميل (بصمة idempotency الحالية تفشل مع الدفعة الجزئية).
4. **حد API» ١٢٠ طلباً/دقيقة لكل رمز** — استيعاب النقاط يحتاج محدّداً مخصصاً (السابقة: `throttle:900,1` لقطع الرفع).
5. **لا هرمية في سجل الوحدات** — `territories.parent_id` أول مرجعٍ ذاتي؛ قائمة الأبناء تأتي من `hub_related` القائمة بلا شيفرة جديدة.
6. **الإسناد المؤرَّخ لا مكان له في نمط `multi` JSON** — إسناد المناطق جدولٌ حقيقي (وحدة) ليحمل «من متى، بأي دور».

## 3) قيود المنتج الصريحة (من المواصفة — تُفرَض من النموذج فصاعداً)

- **ممنوع نهائياً**: باركود طبيب، كود QR بيعي لطبيب، أكواد إحالة، ربط طلبات متجر بطبيب، نسبة مبيعات لطبيب، عمولات/حوافز مالية/أفلييت للأطباء، تتبع مشتريات مرضى عبر طبيب. (حارس اختبارٍ يمنع عودتها: `FieldForceGuardrailsTest`).
- **الخصوصية**: لا تتبع 24/7 — التتبع فقط أثناء جلسة يوم ميداني مصرَّح بها وظاهرة للموظف؛ GPS لا يحدد حالة الحضور؛ العلامات للمراجعة لا للعقاب الآلي؛ المسار التفصيلي بصلاحية دورٍ مخصصة لا لكل مدير؛ سياسة احتفاظ صريحة للنقاط الخام؛ لا تسريب مواقع دقيقة عبر البحث العام.

## 4) مراحل التنفيذ (يُعاد التدقيق قبل كل مرحلة)

- **أ — الأساس (v2.365.0)**: وحدات `hcps` (دليل مقدمي الرعاية) و`facilities` (منشآت بإحداثيات ونطاق) و`territories` (هرمية) و`terrassigns` (إسناد مؤرَّخ) + «الدور الميداني» على `hr`.
- **ب — الدورات والزيارات**: `cycles` بأهداف تغطية وتكرار؛ `visits` (مخططة/طارئة/فائتة) بتقرير مهيكل وعرض منتجات وعينات عبر العهدة؛ أحداث دلالية.
- **ج — اليوم الميداني وGPS**: جلسات تتبع بموافقة ظاهرة فوق Workday؛ استيعاب نقاط دفعي idempotent؛ تبسيط المسار والتوقفات والفجوات؛ خريطة حية وإعادة عرض (OSM/Leaflet — CSP يسمح)؛ تضييق `Permissions-Policy`؛ احتفاظ وتقنين وصول.
- **د — لوحات المشرف وAPI الجوال**: تغطية/تكرار/مخطط مقابل فعلي؛ مسارات v1 بالاصطلاحات القائمة.

## 5) نقاط الربط الحرفية عند الإضافة (قائمة تدقيق كل وحدة جديدة)

`config/hub.php` (تعريف الوحدة + ذيل `rules.mod` + كتلة `events` عند الحاجة) → `config/hub_nav.php` (المجموعة) → `hub_mod_look()` (اللون/الأيقونة) → هجرة بأعمدة المنصة القياسية (`custom/meta/version/archived/created_by/updated_by/timestamps/softDeletes` وعرض نص ≥60) → نموذج بالسمات الست + `MODULE/DISPLAY` → اختبارات على المحرّكين.
