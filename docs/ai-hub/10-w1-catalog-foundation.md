## ٣) عقدُ تعريفِ الحقل

```php
[
    'key'         => string,    // إلزاميّ · فريدٌ داخل المزوّد
    'label'       => string,    // إلزاميّ
    'type'        => enum,      // إلزاميّ · text|password|select|number|url|bool
    'sends_to'    => enum,      // إلزاميّ · credential|config
    'required'    => bool,
    'secret'      => bool,
    'rules'       => array,     // قواعدُ تحقّقِ Laravel
    'options'     => array,     // إلزاميّةٌ لنوع select
    'hint'        => string,
    'placeholder' => string,    // شكلُ القيمةِ — ولا قيمةَ حقيقيّةَ فيه
    'default'     => mixed,     // ممنوعةٌ على السرّيّ
    'show_if'     => array,     // ['<key>' => '<value>']
]
```

**وقائمةُ الخصائصِ صارمة:** ما ليس فيها يُرفَض عند التحميل. فـ`sendsTo` بدل
`sends_to` **خطأٌ يُكشَف** لا خاصّيّةٌ تُتجاهَل بصمت.

### مراجعةُ الخصائصِ المقترحة — وما رُفض منها

| الخاصّيّة | القرار | السبب |
|---|---|---|
| `key` · `label` · `type` · `required` · `options` · `hint` · `default` · `rules` | ✅ **من اصطلاحِ `config/hub.php` القائم** — ١٬٥٨٩ حقلاً تستعمله | لا اصطلاحَ ثانٍ |
| `secret` | ✅ **أُضيفت** | لا نظيرَ لها في الاصطلاح، ويلزم وسمُ السرِّ لفرضِ ثوابتِه |
| `sends_to` | ✅ **أُضيفت** | W0 أثبت وجهتين حقيقيّتين — والفصلُ يجب أن يكون آليّاً |
| `show_if` | ✅ **أُضيفت** | W0 أثبت مصادقتين بديلتين لدى Anthropic |
| `placeholder` | ✅ **أُضيفت** | `hint` جملةٌ تشرح، و`placeholder` شكلٌ يُحتذى — وظيفتان |
| **`aliases`** | ❌ **نُوقشت ورُفضت** | ‏**[C]** المزوّدُ يقبل `GEMINI_API_KEY` أو `GOOGLE_API_KEY` — وهما **اسما متغيّرَي بيئة**، وHub **لا يمرّ بالبيئةِ إطلاقاً**: يُرسل `credential_values` مباشرةً، وفيها **مفتاحٌ منطقيٌّ واحد**. فالخاصّيّةُ تحلّ مشكلةً في طبقةٍ لا يلمسها Hub — وكانت ستكون خاصّيّةً بلا مستهلِك |

> **وحالةُ Anthropic ليست مرادفاً بل مصادقةً بديلة**: `ANTHROPIC_AUTH_TOKEN`
> أسلوبٌ مختلفٌ لا اسمٌ ثانٍ للمفتاح. فمكانُها `show_if` لا `aliases`. والخلطُ
> بينهما كان سيُنتج خاصّيّةً واحدةً تحمل معنيين.
