# المرحلة ٤ — معماريّةُ الحوكمةِ والمحاسبة

## ١) الطبقاتُ وترتيبُها — **والترتيبُ نفسُه ضمانٌ**

```
تخويلُ Hub            hub_can · hub_scope · AskPolicy::canAsk
        ↓  ∩
سياسةُ الذكاء          AiPolicy::evaluate        → POLICY_DENIED
        ↓
صحّةُ النموذجِ والمزوّد  AiGovernance::admitModel  → MODEL_UNAVAILABLE
        ↓
الميزانيّةُ والحصّة      AiBudgets::reserve        → BUDGET_EXCEEDED · QUOTA_EXCEEDED
        ↓
صفُّ السجلّ (reserved)  AiLedger::open
        ↓
التوجيهُ والتنفيذ       AiRouteRun ← governBy · AiChat::complete
        ↓
الإغلاق                settleOk · settleFailed · abandon
        ↓
الأثر                  hub_audit
```

**ولمَ الميزانيّةُ آخرَ ما يُفحَص؟** لأنّها **وحدَها تكتب**. فلو قُدِّمت على
السياسةِ لَحُجز مالٌ لعمليّةٍ ممنوعةٍ ثمّ نُسي الإفراجُ عنه في مسارِ رفضٍ واحد.

## ٢) الجداولُ الأربعة

| الجدول | ما يحمله | لماذا مستقلّ |
|---|---|---|
| `ai_policies` | قواعدُ السماحِ والمنعِ والسقوف | قرارُ إنسانٍ يُدقَّق (`Auditable`) |
| `ai_budgets` | تعريفُ السقفِ والفترةِ والنطاق | قرارُ إنسانٍ يُدقَّق (`Auditable`) |
| `ai_budget_periods` | عدّادُ فترةٍ واحدة | **عدّادٌ تُحرّكه آلافُ العمليّات** — أثرُ تدقيقٍ له يُغرق السجلّ |
| `ai_usage_events` | صفٌّ لكلِّ **محاولة** | **هو** السجلُّ، فأثرُ تدقيقٍ عليه تكرار |

## ٣) دلالاتُ الكلفة — أربعُ درجاتٍ لا واحدة

| الدرجة | من أين | متى تُستعمَل |
|---|---|---|
| `reported` | ترويسةُ البوّابةِ مع الردّ | **الأصدق** — تُسجَّل كما وصلت ولا تُصحَّح |
| `calculated` | رموزٌ **حقيقيّةٌ** × سعرٍ مخزَّن | عدُّها حقيقيٌّ وسعرُها نسخةٌ قد تقدُم |
| `estimated` | رموزٌ **مُقدَّرةٌ** × سعرٍ مخزَّن | **ما يُحجَز به** — ولا يُقدَّم على ما بعدَه |
| `unknown` | لا رقمَ بحال | **تُعَدُّ عدّاً مستقلّاً ولا تصير صفراً** |

> **القاعدةُ الحاكمة: مجهولٌ ≠ صفر.** رقمٌ مجهولٌ حُسِب صفراً يُبطل حارسَ
> الميزانيّةِ في صمت، ويجعل لوحةً تقول «أنفقتَ ٣» عن شهرٍ أُنفقت فيه ٣٠.

**والمالُ عددٌ صحيحٌ بالميكرو** (١٫٠٠ = ١٬٠٠٠٬٠٠٠): عدّادٌ يُقارَن في شرطِ
`UPDATE` متسابقٍ لا يحتمل خطأَ تقريبٍ ثنائيّاً.

## ٤) التزامنُ — حلُّ السباقِ بجملةٍ واحدة

```sql
UPDATE ai_budget_periods
   SET reserved_micro = reserved_micro + :est, requests = requests + 1
 WHERE id = :id
   AND spent_micro + reserved_micro + :est <= :limit_micro
   AND requests < :limit_requests
   AND tokens + :tok <= :limit_tokens
```

الشرطُ والزيادةُ **في عبارةٍ ذرّيّةٍ واحدة**، والقرارُ من **عددِ الصفوفِ
المُعدَّلة**: واحدٌ ⇒ فاز، صفرٌ ⇒ مُنع.

- **ولا `SELECT … FOR UPDATE`** — لا تعرفه SQLite، فكان الحارسُ سيُختبَر على
  محرّكٍ ويعمل على آخر.
- **ولا قفلٌ في التطبيق** — يسقط مع أوّلِ عامِلٍ ثانٍ أو خادمٍ ثانٍ، وهي
  بالضبطِ الحالُ التي بُني لها.

**ودورةُ الحياةِ ثلاثيّةٌ لا ثنائيّة:**

| الحدث | الحجز | المُنفَق | عدُّ الطلبات | لماذا |
|---|---|---|---|---|
| `reserve` | `+est` | — | `+1` | قبل النداء |
| `commit` (نجاح) | `-est` | `+actual` | يبقى | وقع نداءٌ وأُنفق |
| `commit` (فشل) | `-est` | `+actual أو 0` | **يبقى** | **المحاولةُ وقعت** ولو لم تُثمر |
| `release` | `-est` | — | `-1` | **لم يقع نداءٌ** أصلاً |
| `expire` | `-est` | — | `-1` | مات المسارُ بينهما |

## ٥) دلالاتُ الحالاتِ الحدّيّة

| الحالة | السلوك |
|---|---|
| **كلفةٌ لا تُقدَّر + سقفُ مالٍ مفروض** | **تُرَدّ** — المجهولُ لا يمرّ تحت سقفٍ وُضع عمداً |
| **كلفةٌ لا تُقدَّر + بلا سقفِ مال** | تمرّ، ويُعَدّ مجهولُها في `unknown_cost_events` |
| **مهلةٌ بعد الحجز** | `commit` — الطلبُ ربّما وصل وعُولج، فالإفراجُ يكذب |
| **فشلُ المزوّد** | `commit` بكلفةٍ مُبلَّغةٍ إن وُجدت، وإلّا `unknown` |
| **إعادةُ محاولة** | **صفٌّ جديدٌ** `relation = retry` بحجزٍ جديد |
| **احتياط** | **صفٌّ جديدٌ** `relation = fallback` بـ`parent_id` |
| **حجزٌ معلّقٌ فوق عمرِه** | `expired` — ويُفرَج عنه في الدورةِ اليوميّة |
| **رموزٌ أو كلفةٌ سالبة** | تُقصّ إلى صفرٍ عند الحدّ — **لا تُنقص عدّاداً** |
| **التزامٌ أو إفراجٌ مكرَّر** | لا يُنقص العدّادَ تحت الصفرِ (`CASE WHEN`) |

## ٦) السياسة — دلالاتُ التقييم

1. **`hub_allowed` أوّلاً** — وإلّا `UNAUTHORIZED` قبل قراءةِ صفّ.
2. **المنعُ يغلب** — مهما كانت الأولويّةُ ومهما قابله من «اسمح».
3. **قوائمُ السماح** — بُعداً بُعداً (`purpose` · `provider_id` · `model_id`):
   **إن سمّى صفُّ «اسمح» قيمةً في بُعدٍ، صار ذلك البُعدُ قائمةَ سماح.**
4. **`allow_generation = false`** ⇒ منع. و**`allow_tools = false`** ⇒ كتالوجٌ فارغ.
5. **السقوفُ: الأشدُّ يفوز** (`min`) — **والتضييقُ اتّجاهٌ واحدٌ**، فلا ترفع
   سياسةٌ سقفاً أقرّته الإعدادات.
6. **وبلا صفٍّ واحدٍ لا تضييقَ البتّة** — توافقٌ خلفيٌّ مُثبَتٌ باختبار.

`null` في الصفِّ تعني **«أيُّ قيمة»** لا «لا قيمة».

## ٧) تصنيفُ الإخفاق — وخمسةُ رموزٍ جديدة

| الرمز | متى | القرار |
|---|---|---|
| `POLICY_DENIED` | منعُ سياسة | **لا إعادةَ ولا احتياط** — الاحتياطُ التفافٌ لا إنقاذ |
| `BUDGET_EXCEEDED` | سقفُ مال | لا احتياط (صفُّ §٨ القائم) |
| `QUOTA_EXCEEDED` | سقفُ عددٍ أو رموز | كسابقِه |
| `PROVIDER_CREDITS` | **٤٢٩ بنصِّ رصيدٍ نفد**، أو ٤٠٢ | **لا إعادة**، واحتياطٌ **إلى مزوّدٍ آخرَ وحدَه** |
| `MODEL_UNAVAILABLE` | مُعطَّلٌ أو مُزالٌ من المنبع | لا يُنادى أصلاً |

> **و٤٢٩ ثلاثةُ معانٍ لا معنىً واحد:** «لا نشرَ صالحاً» ⇒ انقطاعُ خدمة،
> و«لا رصيد» ⇒ مالٌ نفد، وما عداهما ⇒ حدُّ معدّلٍ ينقضي بمهلتِه.
> **والدليلُ من الحزمةِ المثبَّتة:** `exception_mapping_utils.py` يبني
> `"RateLimitError: {provider} - {message}"` — فنصُّ المزوّدِ ينجو حرفيّاً؛
> و`exceptions.py:21` تفرّق `VENDOR_RATE_LIMIT` من `LITELLM_RATE_LIMIT`
> بنفسِها.

## ٨) ما تُدقّقه الحوكمة

| الفعل | الجدول | كيف |
|---|---|---|
| إنشاءُ سياسةٍ أو تعديلُها أو تعطيلُها أو إزالتُها | `ai_policies` | `Auditable` |
| إنشاءُ ميزانيّةٍ أو تعديلُها أو تعطيلُها أو إزالتُها | `ai_budgets` | `Auditable` |
| **منعُ عمليّةِ ذكاءٍ** (سياسةً أو ميزانيّة) | `ai_usage_events` | `hub_audit` في `AiGovernance` |
| قفزةُ توجيهٍ بعد إخفاق | `ai_profiles` | قائمٌ منذ W7 |

**ولا سرَّ ولا نصَّ سؤالٍ في أيٍّ منها** — تصنيفٌ وسببٌ ومعرّفاتٌ فقط، بعد `Redactor`.
