# ميزانيّةُ مخرَجِ «اسأل Hub» — ولماذا `OUTPUT_LIMIT`

> **الحالةُ:** بعد `v2.580.0` عاد السؤالُ نفسُه `مرحبا كم مشروع لدينا`
> بـ`OUTPUT_LIMIT`. **والتصنيفُ صحيحٌ هذه المرّة** — فالفصلُ الذي بُني في
> الدفعةِ السابقة يعمل، والرسالةُ تُسمّي السببَ الحقيقيّ: **سقفُ ما يكتب
> النموذجُ، لا سعةُ ما يقرأ.**

---

## ١) السلسلةُ كاملةً — من الشاشةِ إلى الحمولة

```
setting('ask.max_output_tokens', 700)     ← القيمةُ المخزَّنة
        ↓  AskPolicy::maxOutputTokens()   ← clamp(القيمة, 700, MIN, HARD)
        ↓  LiteLlmAskGenerator::outputCap() ← min(السقف, سقفِ سياسةِ الذكاء)
        ↓  AiChat::complete($body, $cap)  ← يُعاد فرضُه بعد الدمج
        ↓  payload['max_tokens']          ← ما يصل البوّابة
```

**ولا تسرّبَ من الفاحص.** `AiProbes::MAX_OUTPUT_TOKENS = 16` ثابتٌ لا
يُستعمَل خارجَ `AiProbes` — **مسحٌ على `app/` كلِّها يُثبِت صفرَ استعمال**،
ويحرسه اختبارٌ يقارن الأرضيّةَ بسقفِ الفاحصِ صراحةً.

## ٢) العطبُ المُثبَت — **مدىً بلا أرضيّة**

```php
private static function clamp(mixed $v, int $default, int $hard): int
{
    $n = is_numeric($v) ? (int) $v : $default;
    return max(1, min($hard, $n));   // ← الأرضيّةُ واحد
}
```

قياسٌ حيٌّ على الشيفرةِ قبل الإصلاح:

| القيمةُ المخزَّنة | `maxOutputTokens()` |
|---|---|
| غيرُ مضبوطة | ٧٠٠ |
| `"16"` | **١٦** |
| `"1"` | **١** |
| `"0"` | **١** |
| `"-5"` | **١** |
| `"999999"` | ٢٠٠٠ |

**فسقفٌ بلا أرضيّةٍ ليس حارساً بل بابُ تعطيل.** رقمٌ يُكتَب سهواً في شاشةٍ
يقتل كلَّ سؤالٍ بـ`OUTPUT_LIMIT` **والتهيئةُ تبدو سليمة**. والعيبُ نفسُه في
`ask.max_model_steps`: خطوةٌ واحدةٌ تعني **أداةً بلا جواب**.

## ٣) الأرضيّاتُ الجديدةُ — مشتقّةٌ لا مُختارة

| الحدّ | القيمة | الاشتقاق |
|---|---|---|
| `MIN_OUTPUT_TOKENS` | **٢٥٦** | طلبُ أداةٍ بوسائطِه (≈٤٠ رمزاً) + جوابٌ عربيٌّ قصيرٌ باستشهادِه (≈٦٠) + هامشُ مقدّمة. **وهو ستّةَ عشرَ ضعفَ سقفِ الفاحصِ D** فلا يرث المنتجُ ميزانيّةَ فحص |
| `MIN_MODEL_STEPS` | **٢** | خطوةُ أداةٍ وخطوةُ جواب |
| `MIN_TOOL_CALLS` | **١** | قراءةٌ واحدةٌ على الأقلّ |

**والأرقامُ ليست ادّعاءً:** اختبارٌ يُجري دورةَ عدٍّ كاملةً **عند الأرضيّةِ
نفسِها** فتكتمل بأداةٍ وجوابٍ ومصدر. ولو كانت أصغرَ لَما كانت حدَّ ما يعمل.

والمدى الكامل: **`[256, 2000]`**، والافتراضيُّ **٧٠٠** بينهما. وما دون
الأرضيّةِ يُرفَع إليها، وما فوقَ السقفِ يُخفَض إليه — **ولا قيمةَ غيرُ محدودة**.

## ٤) الدلالات: **لكلِّ خطوةٍ** لا للطلب

`ask.max_output_tokens` سقفُ **الخطوةِ الواحدة**. وأسوأُ حالةٍ نظريّةٍ
`سقفُ الخطوة × عددُ النداءاتِ المسموح`، وكلاهما محدودٌ بسقفٍ صلبٍ في
الشيفرة.

**والحدُّ الكلّيُّ للطلبِ ليس مفتاحاً جديداً** — هو حيث كان منذ المرحلة ٤:
`AiBudgets` تحجز على **كلِّ محاولةٍ** بـ`inTokens + outCap` قبل النداء،
و`limit_tokens` في الميزانيّةِ يمنع الطلبَ الذي يتجاوز. فرفعُ سقفِ الخطوةِ
**يُستهلَك من الميزانيّةِ نفسِها** ولا يلتفّ عليها.

## ٥) النماذجُ التفكيريّة — **الترتيبُ هو التشخيص**

كان الفحصُ:

```php
if ($finish === 'length')  return OUTPUT_LIMIT;   // ← يبتلع الدليل
if ($think !== '')         return MODEL_REASONED_ONLY;
```

ونموذجٌ تفكيريٌّ ينفق ميزانيّتَه في تفكيرِه ثمّ يُقطَع يعود بـ**الاثنين
معاً**: `finish = length` و`reasoning_content`. فيُقال «بلغ الجوابُ سقفَ
طولِه» — **والجوابُ لم يبدأ**. فصار دليلُ التفكيرِ يسبق، لأنّ العلاجَ يختلف:
الأوّلُ يُعالَج برفعِ السقفِ قليلاً، **والثاني بنموذجٍ غيرِ تفكيريٍّ أو
بميزانيّةٍ أوسعَ كثيراً**.

**ورموزُ التفكيرِ صارت تُقرأ**: `usage.completion_tokens_details.reasoning_tokens`
تدخل الاستهلاكَ باسمِها. وهي **رموزُ مخرَجٍ تُدفَع ولا تُرى نصّاً** — فإغفالُها
كان يجعل طلباً أنفق ألفاً يبدو كأنّه أنفق عشرة.

## ٦) الإيجازُ في التوجيه

أُضيف سطرٌ صريحٌ إلى تعليماتِ النظام: **لا سردَ للخطواتِ ولا للأدواتِ ولا
للوحداتِ المتاحة، وسؤالُ «كم» جوابُه جملةٌ واحدة: العددُ ومرجعُه.**
**ولا دعوةَ إلى سلسلةِ تفكير** — يحرسه اختبار.

## ٧) والسقفُ صار مرئيّاً

رسالةُ الإخفاقِ تقول «ارفع سقفَ المخرَجِ من الإعدادات» — **والشاشةُ لم تكن
تعرض كم هو**. صار سطرُ الحدودِ في «اسأل Hub» يقوله: `وسقفُ الجوابِ N رمزاً
لكلِّ خطوة`. وصار `meta.calls` يُعرَض فلا يبدو طلبٌ أنفق نداءين كأنّه لم
يُنفق شيئاً.

## ٨) لماذا لم تكشفه خمسةُ آلافِ اختبار

الحارسُ القائم:

```php
$this->assertSame(AskPolicy::maxOutputTokens(), (int) $body['max_tokens']);
```

**حشوٌ لا حارس** — يقارن الحمولةَ بالدالّةِ التي بنتها. فلو أعادت واحداً
لَمرَّ راضياً **ومات كلُّ سؤالٍ في الإنتاج**. ومثلُه صفٌّ في `AskWiringTest`
كان يُثبِت أنّ `120` تمرّ كما هي — **يحرس العيبَ بوصفِه ميزة**.

والعلاج: **أرقامٌ مطلقة**. `900 → 900` و`16 → 256` و`999999 → 2000`،
ودورةُ عدٍّ تكتمل عند الأرضيّة، ودليلُ التفكيرِ يُقاس بلقطةٍ تحمله.

## ٩) ما لا يُثبَت من هنا

**لا أعرف القيمةَ المخزَّنةَ في قاعدةِ الخادم** — لا وصولَ لي إليها. وما
أُثبِت أنّ الشيفرةَ **كانت تقبل** أيَّ قيمةٍ من ١ إلى ٢٠٠٠، وأنّها **صارت**
تفرض `[256, 2000]`. والقيمةُ الفعليّةُ تُقرأ الآن **من الشاشةِ نفسِها** في
سطرِ حدودِ «اسأل Hub» — بلا نداءِ مزوّدٍ ولا طرفيّة.
