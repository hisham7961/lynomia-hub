# عقدُ الوضعيّة الموسَّع + وضعيّةُ Wi-Fi الشركة (04)

> **مسارُ التصحيح §10–§11.** الحدُّ غيرُ القابل للتفاوض (C15): **«مُنع القراءة»
> ليس امتثالاً**، ووضعيّةُ Wi-Fi من اتصال الجهاز نفسِه فقط — **لا مسحَ شبكة**.

## عقدُ حالةِ الوضعيّة (§11)

كان العقدُ ثلاثيّاً {active|inactive|not-configured} فيخلط ثلاثةَ معانٍ في
not-configured. صار ستّيّاً صادقاً في `App\Support\PostureContract` (ومرآتُه في
الوكيل `internal/security`):

| الحالة | المعنى | امتثال؟ |
|---|---|---|
| `active` | قُرئت فعّالةً حرفياً | **نعم** (الوحيدة) |
| `inactive` | قُرئت معطَّلةً | لا (ثغرة) |
| `permission-denied` | منع النظامُ القراءةَ — لا نعرف | **لا** (§10/§11 صراحةً) |
| `unavailable` | تعذّرت القراءةُ الآن (عابر) | لا |
| `unsupported` | لا ينطبق على هذا النظام | لا |
| `not-configured` | لا قارئَ مُهيّأ | لا |

- `normalize()` يهبط أيَّ قيمةٍ خارج القائمة إلى `not-configured` (لا ادّعاء).
- `isCompliant()` صارمة: `active` وحدَها — و`posture_ok` يعدّها وحدَها.
- الوكيل (Go): أخطاءٌ مُسمّاة `ErrPermissionDenied`/`ErrUnavailable`/`ErrUnsupported`
  تهبط لحالتها الصادقة؛ خطأٌ عامٌّ يبقى `not-configured` (توافقٌ رجعيّ).

## وضعيّةُ Wi-Fi الشركة (§10)

- **الوكيل** يبلّغ SSID **اتصالِ الجهاز نفسِه فقط** (‏`network.WifiPosture`): لا
  مسحَ شبكةٍ ولا LAN ولا ARP — حزمةُ الشبكة لا تفتح أيَّ اتصالٍ أصلاً (يثبته حارسُ
  المصدر). الحمولةُ `{ssid, status}` حيث status ∈ {readable, unavailable}.
- **الخادم** يقيّمه على قائمة SSID المعتمدة في سياسة الجهاز (`EndpointPolicy.approved_ssids`)
  عبر `PostureContract::evaluateWifi`:
  - readable + SSID ضمن المعتمدة ⇒ `active` (على شبكةٍ معتمدة).
  - readable + خارجها ⇒ `inactive`.
  - permission-denied ⇒ `permission-denied` (**ليس امتثالاً**).
  - unsupported/unavailable/بلا SSID ⇒ الحالةُ نفسُها.
  - بلا قائمةٍ معتمدة ⇒ `not-configured` (لا معيار).
  الحالةُ المحسوبةُ تُخزَّن في `posture['wifi']`.

### احترازُ الخصوصيّة (§13)

اسمُ الشبكة (`endpoint_devices.wifi_ssid`) يُخزَّن **حين تكون معتمدةً فقط** — على
شبكةٍ غيرِ معتمدة تُخزَّن الحالةُ `inactive` **بلا اسمِ الشبكة**، فلا نُبقي اسمَ
شبكةٍ شخصيّةٍ قد يكشف مكانَ الموظف. الغرضُ وضعيّةُ الأمن لا تتبّعُ الموقع.

## الترقيةُ والاختبار

- هجرةٌ **إضافيّةٌ محروسةٌ عكوسة** (`2026_09_23_000001`): `approved_ssids` (سياسة) +
  `wifi_ssid` (جهاز). الوضعيّةُ الموسَّعة تُخزَّن في عمود `posture` JSON القائم بلا هجرةِ عمود.
- **إثباتٌ لا ادّعاء:** ٤ اختباراتٍ خادميّة (`EndpointPostureWifiTest`) + اختباراتِ Go
  (`security` العقد الموسَّع، `network` وضعيّةُ Wi-Fi). الحزمتان خضراوان + الوكيل أخضر.
