# دليلُ التشغيل (09)

> إجراءاتُ التشغيل اليوميّة لمنصّة النقاط الطرفية. **بلا مساسٍ بـ`/api/mobile/v1/*`
> (§0/§16):** هويّاتٌ أربعٌ مستقلّة — جهازُ النقطةِ الطرفية ليس جلسةَ جوال.

## تسجيلُ جهازٍ (§1/§2)

1. المركزُ (مالك/مراقب + Step-Up): سكُّ رمزٍ لأصلٍ **مؤهّلٍ مملوكٍ للشركة** (`enroll.mint`).
   - الأصلُ الشخصيُّ/BYOD/المتقاعد/المفقود/التالف: **مرفوضٌ fail-closed**.
2. على الجهاز (Windows/macOS): `lynomia-agent enroll --server <URL> --token <رمز>`.
   - الوكيلُ يولّد هويّةَ P-256 محليّاً (المفتاحُ الخاصُّ لا يغادر)، ويرسل العامَّ فقط.
   - Linux (أو أيُّ نظامٍ آخر): **مرفوضٌ** — Windows/macOS حصراً (§1).

## نشرُ إصدارٍ + طرحٌ مرحليّ (§5–§7)

1. مركزُ التنزيل (مالك + Step-Up): رفعُ ثنائيّةٍ خام — التجزئةُ تُحسب خادمياً.
   - الحالة: `نشرٌ فوريّ` أو `مسوَّدة`؛ والطرح: `all` / `canary %` / `شركة`.
2. المسوَّدة لا يقدّمها البيان؛ نشرُها لاحقاً بزرّ «نشر».
3. الوكيلُ يجلب البيان ويطبّق **بأمان** (لا تنازل، جسرُ ترقية، تحقّقُ sha256 قبل التبديل).

## تكاملُ MDM (§8/§9)

1. `/endpoints/mdm` (مالك + Step-Up): وصلةُ Intune/Jamf — المستأجرُ + سرٌّ في الخزنة.
2. **رصدٌ فقط اليوم:** جسرُ الفرض الحيّ مؤجَّل — لا حجبَ منفذٍ يُزعَم. الفحصُ/المزامنةُ صادقان.

## التشخيص

| العَرَض | الأصل |
|---|---|
| جهازٌ «صامتٌ عن النبض» | لم ينبض خلال ٣× الإيقاع — تحقّق من تشغيل الخدمة والشبكة |
| «غيرُ مُهيّأ» في الوضعيّة | لا قارئَ مُهيّأ؛ «مُنعت القراءة» = صلاحيةُ نظامٍ ناقصة (ليست امتثالاً) |
| USB «رصدٌ فقط» رغم سياسةٍ فارضة | لا مزوّدَ MDM قادرٌ — الفرضُ يتطلب Intune/Jamf حيّاً |
| التحديثُ لا يُطبَّق | البيانُ يستهدف رقعةً لا تضمّ الجهاز، أو النسخةُ ليست أحدثَ، أو جسرُ ترقيةٍ مطلوب |

## أوامرُ الصيانة

- الحزمتان قبل الدفع: `./vendor/bin/phpunit` و`./vendor/bin/phpunit -c phpunit.mysql.xml`.
- الوكيل: `cd agent && go test ./... && gofmt -l . && go vet ./...`.
- OpenAPI بعد تغيّرِ مسارٍ/إعدادٍ/نسخة: `php artisan hub:openapi --out=docs/openapi.json`.
