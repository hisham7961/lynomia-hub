# التسجيلُ وملكيّةُ الأصل (01) — التصحيح §2

> **الغاية:** وكيلُ النقطةِ الطرفية لحواسيبِ الشركةِ المُدارة/المملوكة — لا يُسجَّل على
> حاسوبٍ شخصيٍّ عشوائيّ. الأصلُ (سجلُّ العهد القائم) هو مصدرُ الحقيقة، والإسنادُ خادميّ.

## المفهومُ يُعاد استعمالُه (لا جدولُ أجهزةٍ ثانٍ)

- **الأصل** (`assets`) يمثّل عتادَ الشركةِ الفعليَّ (بكودٍ وملصقٍ وعهدةٍ وصيانة).
- **الملكيّة** من `assets.owner_scope` القائم — أُضيفت إليه قيمةُ «شخصي — BYOD» (إضافةُ
  خيارٍ لا عمود). كلُّ القيمِ الأخرى (لينوميا/عميل يُدار لدينا/مشترك، أو فارغة=لينوميا)
  **مُدارةٌ للشركة** ومؤهّلة؛ «شخصي — BYOD» وحدَها غيرُ مؤهّلة (fail-closed).
- **لا عمودَ ملكيّةٍ ثانٍ، ولا جدولَ عهدةٍ ثانٍ** — `Custody`/`AssetCustody` تبقى المصدر.

## أهليّةُ الأصلِ لنقطةٍ طرفيّة (`Asset::endpointEligible`)

مؤهّلٌ ⇔ **له شركة** و**مُدارٌ للشركة** (لا BYOD) و**حالتُه صالحة**. غيرُ المؤهّل
(الحالاتُ المنتهية/المفقودة/التالفة): `مستبعد`, `مباع`, `مُعاد للمورد`, `مفقود`, `تالف`.
الحالةُ تُطبَّع عبر `Custody::canonicalStatus`. **fail-closed:** الغموضُ ⇒ رفض.

## تدفّقُ التسجيل (خادميٌّ بالكامل)

```
المسؤول (مالك/مراقب)
  → يختار أصلاً مؤهّلاً مملوكاً للشركة (القائمةُ تُخفي BYOD وغيرَ المؤهّل)
  → تصعيدُ هويّة (Step-Up)
  → الخادمُ يسكّ رمزاً لمرّةٍ واحدة (sha256، قصيرَ المهلة) **مربوطاً بالأصل**:
      company_id / employee_id / station_id  ← كلُّها من الأصل، لا من المُدخِل
  → الوكيلُ يرسل هويّتَه ومفتاحَه العامَّ + الرمز
  → الخادمُ يُعيد التحقّق (أهليّةٌ + لا جهازَ نشطٌ للأصل) ثم يُنشئ EndpointDevice
      يرث company/asset/employee/station **من الرمز** (لا من الحمولة)
  → الرمزُ يُستهلَك ذرّياً (لا جهازين برمز)
```

**الجهازُ لا يختار:** `company_id`/`employee_id`/`station_id`/`asset_id` — كلُّها خادميّة.

## القواعدُ المفروضة (§2) — كلُّها مُثبَتةٌ باختبار

| القاعدة | السلوك |
|---|---|
| أصلٌ من شركةٍ أخرى | ٤٠٤ (لا تسريبَ وجود) |
| أصلٌ شخصيّ/BYOD | يُرَدّ (لا رمز) + إشارةُ `SecurityRadar` بلا سرّ |
| أصلٌ منتهٍ/مباع/مُعاد/مفقود/تالف | يُرَدّ (fail-closed) |
| موظّفٌ/محطّةٌ مؤكَّدةٌ لا تطابق الأصل | يُرَدّ |
| للأصلِ جهازٌ نشطٌ فعلاً | يُمنَع التسجيلُ المكرَّر (يُتقاعَد أولاً) |
| رمزٌ مُستهلَك/منتهٍ | ٤٠٩/٤٠١ |
| أصلٌ صالحٌ مملوكٌ للشركة | يُسجَّل، والجهازُ يرث إسنادَه خادميّاً |
| الاستبدال بعد التقاعُد | يُقبَل، والتاريخُ محفوظ (الجهازُ القديم لا يُحذَف) |

## التدقيقُ والإشارات

كلُّ سكٍّ وكلُّ تسجيلٍ ناجحٍ مُدقَّق (`hub_audit`، بلا نصِّ رمزٍ صريح). محاولةُ سكٍّ
لأصلٍ غيرِ مؤهّلٍ تُسجّل إشارةَ `SecurityRadar` (`endpoint-enroll-blocked`) **بلا أسرار**.
