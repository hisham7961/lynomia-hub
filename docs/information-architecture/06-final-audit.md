## 4) الأثرُ (لا إعادةَ تصميمٍ بصريّ)

- **لا CSS ولا لونٍ ولا مكوّنٍ جديد:** كلُّ العرضِ بأصنافٍ قائمة (`.ni`/`.navsection`/`<details>`/
  `.crumbs`/`.card`/`.stat`)، والصنفُ البنيويُّ الوحيدُ (`iacrumb`) مُسجَّلٌ مقبضاً.
- **إضافيٌّ بالكامل:** لا حذفَ مسارٍ/صفحةٍ/إجراءٍ/تقريرٍ/مركزٍ؛ الإضافةُ مسارانِ اثنان فقط.
- **مصدرٌ واحدٌ للحقيقة** يُغذّي كلَّ الأسطح — فما يظهر في الشريط يظهر في الخريطة والبحث والجوال، متطابقاً.
