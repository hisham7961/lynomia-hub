### ⚠️ قيدُ الترتيب الوحيد

`config/hub.php` يُعلن حقلَ `issues.due`، **والمحرّكُ العامُّ لا يحرس عموداً
غائباً** في هذا الموضع (`hub_has_col` مستعملٌ لـ`deleted_at` و`completed_at`
لا للحقولِ المُعلَنة).

**والعلاجُ لا يحتاج إثباتَ العطل:** تُشغَّل **الهجرةُ أوّلاً ثمّ تُنشَر
الشيفرة**. عمودٌ زائدٌ لا يكسر شيفرةً قديمةً أبداً، فالترتيبُ آمنٌ في كلِّ
الأحوال. (وهذا هو الانضباطُ المعتاد: وسّع ← رحّل ← انشر.)

## ٥) ما يُنسَخ قبل النشر — **إلزاميّ**

1. **قاعدةُ البيانات**: `php artisan hub:backup --keep=14` (أو `mysqldump` كاملٌ
   إن كان أوثق). **ويُتحقَّق من حجمِ الملفِّ الناتجِ بعدها** — نسخةٌ صفريّةُ
   الحجمِ ليست نسخة.
2. **تسجيلُ نقطةِ العودة**: `git rev-parse HEAD > ~/hub-rollback-point.txt`
   (‏`14d3f44`). **قبل أيِّ أمرِ git.**
3. **`storage/app/hub`**: نسخةُ Hub لا تشمل الملفّاتِ المرفوعة — تُنسَخ
   بآليّةٍ مستقلّة (موثَّقٌ في `RUNBOOKS §8`).
4. **`.env`**: نسخةٌ جانبيّةٌ بصلاحيّة `0600` خارج شجرةِ المستودع.

## ٦) ملفّان لا يُمَسّان

| الملف | الحكم |
|---|---|
| `error_log` | **لا يُحذَف ولا يُعدَّل.** مخرجُ PHP على الخادم؛ ليس من المستودع. يبقى غيرَ متعقَّب (`untracked`) ولا يعترض `git pull`. |
| `public/storage` | **رابطُ Laravel الرمزيّ** المتوقَّع (`storage/app/public`). **لا يُحذَف ولا يُعاد إنشاؤه بلا داعٍ**: حذفُه يقطع كلَّ رابطِ ملفٍّ عامٍّ حتّى يُعاد. **ويجب التحقّقُ أوّلاً** أهو رابطٌ صحيحٌ أم مجلّدٌ حقيقيّ — والثاني حالةٌ مختلفةٌ تماماً تُوقف الخطّةَ وتُناقَش. |

**ولماذا الشجرةُ غيرُ نظيفة؟** لأنّ كليهما **غيرُ متعقَّب** لا مُعدَّل:
مخرجُ تشغيلٍ ورابطُ تنصيب. وهذا **طبيعيٌّ في تنصيبِ Laravel**، وليس انحرافاً
يُصحَّح. `git pull` لا يمسّ غيرَ المتعقَّب.

> **ولا `git reset` ولا `git clean` ولا `checkout -f` في أيِّ خطوة.** كلُّها
> تحذف غيرَ المتعقَّب أو تدهس تعديلاتٍ محلّيّة — وأحدُها يكفي لإتلافِ
> `public/storage` أو `error_log`.

## ٧) إجراءُ النشر المقترَح

```bash
cd /home/lynomia/public_html/hub-lynomia-com

# (٠) نقطةُ العودة والنسخة — قبل كلِّ شيء
git rev-parse HEAD > ~/hub-rollback-point.txt && cat ~/hub-rollback-point.txt
php artisan hub:backup --keep=14 && ls -lh storage/app/backups | tail -3

# (١) جلبٌ بلا تغييرِ شجرة
git fetch origin

# (٢) معاينةُ ما سيصل — قراءةٌ فقط
git log --oneline HEAD..origin/claude/lynomia-hub-enterprise-upgrade-xn4p2t
git diff --stat HEAD...origin/claude/lynomia-hub-enterprise-upgrade-xn4p2t

# (٣) الهجرةُ أوّلاً — عمودٌ يقبل العدم، آمنٌ قبل الشيفرة
php artisan migrate --force

# (٤) الشيفرة — دمجٌ يحفظ تاريخَ الإنتاج (لا reset ولا checkout -f)
git merge --ff-only origin/claude/lynomia-hub-enterprise-upgrade-xn4p2t \
  || git merge --no-edit origin/claude/lynomia-hub-enterprise-upgrade-xn4p2t

# (٥) تنظيفُ المخابئ — بلا إعادةِ بناءِ تبعيّات (لا تغييرَ فيها)
php artisan optimize:clear

# (٦) إثباتُ الوصول
cat VERSION            # يجب أن يطبع 2.559.0
php artisan hub:schema-check
```

**ولا `composer install`**: `composer.lock` لم يتغيّر. وتشغيلُه بلا داعٍ يخاطر
بسحبِ تبعيّاتٍ أو كسرِ `autoload` في نافذةِ نشر.
