## §89 — التقريرُ الختاميّ

بُني المركزُ على تسعِ دفعاتٍ (v2.438.0 → v2.446.0)، كلٌّ منها الحزمتان خضراوان (SQLite + MySQL):

| الدفعة | التبويب/المحتوى |
|---|---|
| v2.438.0 | الأساس + نظرةٌ عامّة + بطاقةُ جاهزية + صحّة |
| v2.439.0 | الجلسات + الأجهزة + جهاز 360 |
| v2.440.0 | الدفع (حالة/رموز/سجلّ/اختبار آمن) |
| v2.441.0 | التطبيق والإطلاق (إصدارات/app-config/روابط عميقة) |
| v2.442.0 | الـAPI والقدرات (مُستكشِفُ مسارات/سجلُّ قدرات/مزامنة) |
| v2.443.0 | الأمن والتليمتري (موقف/تدقيق/تبنٍّ) |
| v2.444.0 | الملفات والماسح والتتبّع (بلا مراقبة) |
| v2.445.0 | الوثائق (فهرسٌ حيٌّ + عارضٌ آمن) |
| v2.446.0 | التدقيقُ الختاميّ + الوثائق + التقرير |

**ثوابتُ مُثبَتة:** تكرارُ الخلفيّة = 0 (صفرُ هجرةٍ جديدة) · صفرُ سرٍّ يُعرَض (كناريّاتٌ في كلِّ تبويب) ·
لا مراقبةَ موقعٍ (كناريّةُ إحداثيّات) · لا اجتيازَ مسارٍ في عارضِ الوثائق · `/api/mobile/v1` و`/api/v1` بلا كسر.
