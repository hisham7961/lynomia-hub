# مركزُ منصّة تطبيق الهاتف — خريطةُ التهيئة (03)

> **الغاية:** أيُّ مفتاحِ إعدادٍ يُغيّر أيَّ حالةٍ في المركز، وأين يُضبط — كلُّه في **صفحةِ
> الإعدادات القائمة** (لا نظامَ إعداداتٍ ثانٍ). المركزُ **يعرض** الحالةَ ويربط بمِرساةِ الضبط.

## الدفع (تبويب push / config)

| المفتاح | الأثر | يُضبط في |
|---|---|---|
| `mobile.push_driver` | `fcm` يفعّل مزوّدَ FCM؛ غيابُه ⇒ `NullPushProvider` (NOT_CONFIGURED) | الإعدادات #mobile.push_driver |
| `mobile.push_fcm_project_id` | حضورٌ (لا قيمة تُعرَض) | الإعدادات |
| `mobile.push_fcm_access_token` | حضورٌ — **لا يُعرَض المفتاحُ قط** | الإعدادات |

## الإصدارات وبوّابة التحديث (تبويب config)

| المفتاح | الأثر |
|---|---|
| `mobile.latest_version_ios` / `_android` | الإصدارُ الأحدثُ المُعلَن |
| `mobile.min_version_ios` / `_android` | الحدُّ الأدنى — دونه `update_required` (حجب) |
| `mobile.store_url_ios` / `_android` | رابطُ المتجر |
| `mobile.force_update` | إلزامُ التحديثِ حين العميلُ دون الحدّ |

- **صحّةُ الضبط:** `min > latest` (semver) ⇒ «ضبطٌ باطل» يظهر صراحةً.
- **الفعّاليّة:** تُعاين عبر نقطةِ `MobileAuthController@appConfig` الحيّة نفسِها (لا نسخةٌ تتباعد).

## الروابط العميقة والوثائقُ العالميّة (تبويب config)

| المفتاح | الأثر |
|---|---|
| `mobile.dl_apple_team_id` + `mobile.dl_apple_bundle_id` | تُهيّئ AASA (Universal Links) |
| `mobile.dl_android_package` + `mobile.dl_android_fingerprints` | تُهيّئ assetlinks (App Links) |

- الحالةُ الحيّة من `MobileWellKnownController` نفسِه (ترويسة `X-Deep-Links-Status`).
- حتى الضبطِ: وثيقةٌ صحيحةُ البنية تربط **صفرَ تطبيق** (صدقُ NOT_CONFIGURED — لا ربطَ مُختلَق).

## أسبقيّةُ القراءة: setting فوق config

كلُّ مفتاحٍ يُقرأ `setting('mobile.*', config('hub.mobile.*'))` — الإعدادُ الحيُّ يغلب الافتراضَ المُجمَّع.
هذه هي الأسبقيّةُ نفسُها التي تعتمدها النقاطُ الحيّة، فلا انحرافَ بين ما يعرضه المركزُ وما يتلقّاه العميل.

## قائمةُ فحصِ الإطلاق (تبويب config)

تجمع الحالاتِ الحقيقيّة لكلِّ ما يوفّره فريقُ التطبيق قبل النشر (معرّفاتُ الروابط، روابطُ المتجر،
الإصدارات، مزوّدُ الدفع) — «غير مُهيّأ» شرطُ إطلاقٍ خارجيٌّ لا عُطل.
