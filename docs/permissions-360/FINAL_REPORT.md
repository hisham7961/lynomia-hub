# Permissions 360 — التقريرُ النهائيّ (المراحل 0–4)

> **الغاية:** صلاحيّاتٌ دقيقةٌ قابلةٌ للمنحِ والمنعِ والتفسير، **على المحرّكِ القائمِ نفسِه**
> (`role.matrix` + `role.flags` + `field_rules` + `hub_scope`) — لا محرّكَ توثيقٍ ثانٍ،
> ولا كسرَ لأحد: كلُّ تفكيكٍ إضافيٌّ (الرايةُ الأصليّةُ تبقى مفتاحاً رئيساً) أو مصحوبٌ
> بهجرةٍ عديمةِ الخسارة (من كان يرى مُنح).

**نطاقُ الإنجاز:** v2.478.0 → v2.495.0 · **83/83** نتيجةً مُغلقةً (اثنتا P1 كلتاهما، وكلُّ P2 وP3 — 81 بإصلاحٍ مُختبَرٍ فاشلاً أولاً واثنتان بتوثيقِ قصدٍ: 14.1/03.4) · كلُّ دفعةٍ خضراءُ على المحرّكين (SQLite + MySQL، ~3840 اختباراً).

## 1) الآليّاتُ المبنيّة (لا محرّكَ ثانٍ)

| الآليّة | الموضع | ما تفعله |
|---|---|---|
| كتالوجُ المفاتيحِ الدقيقة | `config/hub_permissions.php` | كلُّ مفتاحٍ مسمّى (label/hint/modules/risky) — المحرّرُ يحفظُه ويعرضُه، والفاحصُ يفسّرُه. أسماءٌ بلا نقاط (قيدُ تحليلِ المحرّر) |
| قراءةُ المفاتيح | `hub_can($u, $module, $key)` | نفسُ دالّةِ المصفوفة تقرأ أيَّ مفتاحٍ مسمّى (المالكُ يتجاوز) |
| مجموعاتُ المراقبة | `hub_monitor_group($group)` | `hub_monitor() \|\| hub_flag($group)` — monitor تبقى جامعةً، والمجموعةُ منحٌ أضيق |
| الوثائقُ الحسّاسة | `hub_doc_sensitive` + `DocumentPolicy` (docsec) | نوعُ وثيقةٍ حسّاسٌ يُحجب إلا عن حاملِ `docsec` على وحدتِه |
| الحقولُ الحسّاسة | `config/hub_field_sec.php` + `hub_field_mode` (fieldsec) | حقلٌ حسّاسٌ يُحجب قبل قواعدِ الدورِ إلا عن حاملِ `fieldsec` — يسري على كلِّ سطحٍ يستشير الدالّة |
| نطاقُ مفتاحِ API | `ApiToken::allows` عند كلِّ بوّابة | المفتاحُ يُقيّد كصلاحيّةِ المستخدم لا يتجاوزها |
| التفسير | `PermissionInspector::finePerms/flags` + `/admin/access` | «ماذا يفتح هذا المفتاحُ ولمن مُنح؟» دون قراءةِ الكود |
| هجراتٌ عديمةُ الخسارة | `grant_docsec…` · `grant_fieldsec…` | من كان يرى يومَ التفعيل مُنح — لا فقدَ فوريّاً، والمنعُ صار ممكناً |
| بوّابةُ سلامةِ الكتالوجات | `Permissions360CatalogIntegrityTest` | CI يُسقط أيَّ انحرافٍ يجعل حمايةً ميّتةً صامتةً (حقلٌ أُعيد تسميتُه، وحدةٌ وهميّة، مفتاحٌ بنقطة) |

## 5) قواعدُ الاستمرار

1. **مفتاحٌ جديد** يُعلَن في `hub_permissions.php` (بلا نقاط) قبل أوّلِ `hub_can` عليه — وإلا محاه المحرّرُ عند الحفظ (تحرسه بوّابةُ السلامة).
2. **حقلٌ حسّاسٌ جديد** يُضاف إلى `hub_field_sec.php` بمفتاحِ الحقل — البوّابةُ تُسقط أيَّ مفتاحٍ ميّت.
3. **تضييقُ سلوكٍ قائم** لا يمرّ إلا بهجرةٍ عديمةِ الخسارة تمنح من كان يرى.
4. **كلُّ بوّابةٍ جديدة** بثلاثيّتِها معاً: بوّابةُ المتحكّم + ظهورُ الشريط + حارسُ IA (وإلا سقط `IaGuardParityTest`).
