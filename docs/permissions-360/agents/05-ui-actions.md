# 05 — واجهة Blade: الأزرار والنماذج والإجراءات

> وكيلُ تدقيقٍ للقراءة فقط (Permissions 360 · المرحلة 0). مصدرُه سيرُ التدقيق `wf_8fdd85b1-7b4`.

## الخلاصة

Swept resources/views (373 blades) for actionable elements (create/edit/delete/restore/export/import/bulk/approve/reject/reveal/download/assign/member-mgmt/pay/post/apply) and matched each to its server route gate. The single hub_can/hub_flag/hub_field_mode engine is applied consistently: the generic module CRUD (modules/index,show), custody-wallet, esign, approvals, clients-members, staff-account, security/ops/webhooks/flows/fields/features admin, attachments and DM are all correctly server-gated (hub_can + hub_scope, owner-only + stepup, or approver flag) and the UI guards mirror them. Secrets are never emitted to source (reveal fetch is server-gated with field_mode+allowlist) and CSV masks sec + drops hidden columns. Real defects are narrow: (1) file/img field downloads via file.show ignore field_mode 'hide' while every other surface honors it; (2) a few UI buttons are shown under a weaker guard than the server enforces (payroll approve, changeorder apply) so they 403 for some users; (3) project P&L is reachable via costs.index under the monitor flag alone, diverging from the field-mode gate used on the project-360 finance tab. Sensitive financial state-transitions (journal post, stock post, invoice payment, quote conversion) and per-module export are gated only by broad module 'e'/global 'exp' and warrant fine-grained keys.

## اختبارات مطلوبة

- hr role with field_rules {hr:{<fileField>:hide}} + hr.v: GET files/{path} for that hidden file field must 403 (currently 200) — fails first, then fix mayRead.
- payroll.e role WITHOUT approve flag: POST payroll/{id}/act do=approve must 403 (already enforced) AND the Approve button must not render in the view.
- changeorders.e role WITHOUT projects.e: the apply button must not render; POST changeorder/{id}/apply must 403 (already enforced).
- monitor-flag role with field_rules {projects:{cost:hide,budget:hide}}: GET costs?p={id} must NOT expose cost/profit/margin/budget (parity with project-360 finance tab).
- exp-flag role with hr.v but a role-hidden salary column: GET m/hr/export CSV must exclude the hidden column and mask any sec columns (regression guard for columnsAndLabels + streamCsv).
- copySec role with allowed_ids allowlist excluding the user: POST m/{module}/{id}/secret/{field} must 403 (allowlist), and with field_mode hide must 403 (regression).
- client-account (PortalGuard) user: costs.index, graph.explore, /m/* financial partials, and file.show for internal records must 404/403.
