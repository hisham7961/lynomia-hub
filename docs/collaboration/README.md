## المبادئُ الحاكمة

- **محرّكٌ واحد:** لا جدولَ رسائلَ ثانٍ ولا محرّكَ تفاعلاتٍ ثانٍ.
- **العزلُ خادميّ:** `guardConversation` · `dmReachable`+مفتاحٌ من `auth()` (F8) · `guardTarget` ·
  `PortalGuard` · دفاعُ النطاق — القوائمُ مرآةٌ لا بابٌ يلتفّ على الحارس.
- **صدقُ النقل:** `POLLING` اليوم، والعقدُ `READY` للبثّ بلا تغيّرِ الواجهة.
- **تواصلٌ لا مراقبة:** الحضورُ خشنٌ والكتابةُ عابرةٌ لا تُدقَّق.
- **العربيّةُ أولاً (RTL)** · **الحزمتان خضراوان** على كلِّ دفعة.
