# 05 — نموذجُ النطاق (§20/§38/§39)

## ثلاثُ طبقاتٍ يحقنُها `hub_scope`

1. **نطاقُ المشروع** — إن `Role.scope === 'proj'` (وليس مالكاً): يُقيَّد بـ`visibleProjectIds()`.
2. **عزلُ الشركة** — إن `users.companies` غيرُ فارغة: `whereIn(company_col, ...)`.
3. **عزلُ العميل** — إن `users.clients` غيرُ فارغة: `whereIn(client_col, ...)`.

كلُّها تنهار (no-op) للمالك.

## «الفارغُ» يُوصَف صراحةً (§20)

- `companies = null` ⇒ **كلُّ الشركات** (لا قيد). `companies = []`/محدَّدة ⇒ تلك فقط.
- المُفسِّرُ وشاشةُ التشخيصِ يعرضان هذا حرفاً: «كلُّ الشركات (لا قيد)» أو «n شركةً محدَّدة».

## الصلاحيّةُ ≠ نطاقُ السجلّ (§38/§39)

«يدخل المشاريع» غيرُ «يرى كلَّ مشروع». عرضٌ ممنوحٌ + نطاقٌ = مشاريعُ مُسنَدة ⇒:
- تنقّلُ المشاريعِ مرئيّ، والصفحةُ مفتوحة، والبياناتُ مقيَّدةٌ بالمُصرَّح.
- **قائمةٌ فارغةٌ ليست منعاً:** لا تُخفى الوحدةُ لأنّ عدَّ السجلّاتِ = 0. المُفسِّرُ يقول صراحةً:
  «السجلّاتُ مقيَّدةٌ بـ… — قائمةٌ فارغةٌ ليست منعاً».

## الحالاتُ الأربعُ المميَّزة (§13)

| الحالة | المعنى | مصدرُ الحسم |
|---|---|---|
| `ALLOWED` | مسموح (قد يكون النطاقُ فارغاً) | مصفوفةُ الدور + hub_can |
| `DENIED_ROLE` | الدورُ يمنع العرض | المصفوفة |
| `DENIED_CLIENT` | حدُّ نوعِ الحساب (عميل) يعلو | `PortalGuard::MODULE_ALLOW` |
| `FLAG_GOVERNED` / `OWNER` | محكومةٌ بعلَمٍ (users) / تجاوزُ المالك | راية / is_owner |

لا تُطوى الأربعُ في «غير مرئيّ» — وهذا كان جوهرَ الالتباس.
