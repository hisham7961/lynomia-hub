# 02 — خريطةُ صلاحيّةِ الوحدات (كلُّ الوحدات · §91)

**كلُّ وحدةٍ CRUD** تدعم العملياتِ الأربع `v/a/e/d` عبر `Role.matrix`، وتُبوَّب بـ`hub_can($u,$key,$op)`
(GET→v على API). فالعمودُ «الصلاحيّة» ليس ذاتيّاً للوحدة بل يُضبَط لكلِّ دور. الجدولُ أدناه يُظهر
**الهُويّةَ القانونيّة** لكلِّ وحدة: المفتاح، الاسم، بيتُها في التنقّل/IA، وحدُّ نوعِ الحساب.

- **مصدرُ الحقيقة:** `config('hub.modules')` (85 وحدة).
- **العمليّات:** `v`=عرض · `a`=إضافة · `e`=تعديل · `d`=حذف — كلُّها متاحةٌ لكلِّ وحدةٍ عبر المصفوفة.
- **بيتُ التنقّل:** مجموعةُ `config/hub_nav.php` (والشريطُ الفضائيّ يشتقّ منها عبر IA). «—» = بلا
  بندِ شريطٍ مباشر؛ بيتُها IA (مركز/إداريّ) أو مؤرشفة.
- **نوعُ الحساب:** «عميل+داخلي» = ضمن `PortalGuard::MODULE_ALLOW` (يبلغه العميلُ مُنطَّقاً صفّيّاً)؛
  «داخلي» = داخليٌّ فقط (٤٠٤ للعميل).
