# مركزُ القدرات الإداريّ (07)

> **الإدارة ← التهيئة ← القدرات** (`admin/features`) — للمالكِ حصراً. سطحُ تحكّمٍ ناضجٌ يشرح
> **لماذا** الحالةُ كما هي، بلا حالةٍ خضراءَ مضلِّلة ولا زرٍّ ميّتٍ ولا كشفِ سرّ.

## المسارات

| المسار | الفعل |
|---|---|
| `GET admin/features` | القائمةُ + بطاقاتُ الملخّص + المرشّحات (`features.index`) |
| `GET admin/features/{key}` | تفصيلُ القدرة (`features.show`) |
| `POST admin/features/{key}/toggle` | تبديلُ الاختياريّة عبر Settings (`features.toggle`) |

الحارس: `abort_unless(hub_is_owner(), 403)` (نظيرُ `SettingController`). العميلُ محجوبٌ بالبوّابة
(٤٠٤). مُصنَّفٌ في `hub_ia.php` (الإدارة ← الإعدادات) و`hub_admin_links` — فيظهر في الشريطِ والبحثِ
ولوحةِ الأوامرِ وخريطةِ النظام تلقائيّاً (للمالكِ وحدَه).

## الصفحةُ الرئيسة

- **بطاقاتُ ملخّصٍ لكلِّ حالةٍ** من الحالاتِ التسع (عددٌ لكلٍّ، نقرةٌ ترشّح).
- **بحثٌ** (اسم عربيّ/إنجليزيّ · مفتاح · مجال · حالة · اعتماد · مزوّد) + **مرشّحات** (مجال · حالة ·
  قابلٌ للتبديل · ثابتٌ نظاميّ · اعتمادٌ خارجيّ · خلفيّةُ جوالٍ جاهزة · يحتاج تهيئة).
- **مجمَّعةٌ بالمجال** — لا جدولٌ واحدٌ ضخم.

## تفصيلُ القدرة (يجيب كلَّ سؤالٍ في §9)

ما هي · حالتُها وسببُها · أمتاحةٌ · أقابلةٌ للتبديل · لماذا لا تتوفّر · اعتماديّاتُها ·
أنظمتُها الخارجيّة · من يُديرها · من يستعملها · أين · واجهاتُ API · الجوال (خلفيّة/أصيل/OpenAPI) ·
النسخة · التوثيق · التاريخ (للقابلِ للتبديل) · التبديلُ الآمن (بسببٍ اختياريّ).

## الجودةُ الإداريّة (§22)

عربيٌّ أوّلاً · RTL كامل · دعمُ الإنجليزيّة (العنوانُ الإنجليزيُّ لكلِّ قدرة) · شاراتُ حالةٍ صادقةٌ
(لا خضراءَ مضلِّلة) · شرحُ حالةِ التهيئة · تحذيراتُ الحواجز · **لا أسرارَ تُعرَض** (السجلُّ لا يقرأ
قيمةَ سرٍّ قطّ — الأسرارُ تبقى في مركزِ الإعدادات مطموسةً). حالاتٌ فارغةٌ مفيدة عند غيابِ المطابقة.
