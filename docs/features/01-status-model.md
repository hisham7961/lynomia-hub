# نموذجُ حالةِ القدرة (01)

> حالةٌ **مطبَّعةٌ صادقة** لكلِّ قدرة — تُشتقُّ من **الكود + الإعدادات + فاحصاتِ الاتصال**،
> لا من تفاؤلٍ يدويّ. الواجهةُ تشرح **لماذا** الحالةُ كما هي.

## الحالاتُ التسع (`App\Support\FeatureStatus`)

| الحالة | الدلالة | مثال |
|---|---|---|
| `ENABLED` | منفَّذةٌ ومُختبَرةٌ ومتاحةٌ الآن | مركز التواصل · القنوات |
| `DISABLED` | منفَّذةٌ لكنْ **مُطفأةٌ عمداً** حيث يأمن الإطفاء (اختياريّةٌ حصراً) | قدرةٌ اختياريّةٌ عطّلها المالك |
| `READY` | التنفيذُ/المتطلَّبُ مكتمل، لكنّ خطوةً منتَجيّةً/تفعيليّةً تاليةً غيرُ نشطةٍ عمداً | عقدُ WebSocket جاهزٌ ومزوّدُ الزمنِ الحقيقيّ غيرُ مُهيَّأ |
| `DEVELOPMENT` | ناقصةٌ أو غيرُ جاهزةٍ للإنتاج | — |
| `DEFERRED` | مؤجَّلةٌ عمداً | Voice Notes · Link Previews · التطبيقُ الأصيل |
| `NOT_CONFIGURED` | التنفيذُ موجودٌ لكنّ البنيةَ/المزوّدَ/الاعتماداتِ/الإعدادَ التشغيليَّ غائب | Production Push بلا اعتمادات |
| `EXTERNAL` | تعتمد أساساً على مزوّدٍ/إجراءٍ خارجَ Lynomia | تزويدُ شرائح الاتصال الحيّ |
| `DEGRADED` | متاحةٌ بوضعٍ مُخفَّضٍ/احتياطيّ | — |
| `SYSTEM_INVARIANT` | سلوكٌ أمنيٌّ/منصّيٌّ إلزاميٌّ **لا يصير مفتاحاً** أبداً | `hub_can` · عزلُ العميل · سلسلةُ التدقيق |

## قواعدُ حاكمة

- **لا حالةَ متفائلة:** الحالةُ تُشتقُّ من الحقيقة لا تُدّعى. `NOT_CONFIGURED`/`EXTERNAL` لا
  تُعرَض `ENABLED` أبداً بلا دليلٍ من الكود/فاحصِ اتصال.
- **الشرح إلزاميّ:** كلُّ حالةٍ غيرِ `ENABLED` تحمل **سبباً** (`status reason`) يُعرَض في الواجهة.
- **التوافرُ ≠ الصلاحية:** كون القدرةِ `ENABLED` لا يمنح إذناً؛ وامتلاكُ الإذنِ لا يعني أنها
  مفعّلة. الفحصان مستقلّان (`القدرةُ متاحةٌ؟` و`المستخدمُ مصرَّحٌ له؟`).
- **الثوابتُ الأمنيّة `SYSTEM_INVARIANT`:** بلا زرِّ إطفاء، بلا مفتاحِ تشغيلٍ زمنيّ، بلا تجاوزٍ
  عبر الاستيراد، بلا انتقالٍ عبر API إلى `disabled`، بلا تجاوزٍ إداريّ. تظهر للرؤيةِ فقط.

## الانتقالاتُ الممنوعة (تُرفَض خادميّاً)

- `SYSTEM_INVARIANT → DISABLED` — ممنوعٌ مطلقاً.
- `NOT_CONFIGURED → ENABLED` حين تغيبُ الاعتمادياتُ الإلزاميّةُ فعلاً.
- `DEFERRED → ENABLED` حين يكون التنفيذُ غائباً موضوعيّاً.

## اشتقاقُ الحالة (لا تكرار)

- **البنيويّةُ** (هل الكودُ موجود؟ هل التنفيذُ مكتمل؟) — من كتالوجِ السجلّ الكوديّ.
- **الزمنيّةُ القابلةُ للضبط** (مُفعَّلٌ/مُطفأ) — من مركزِ الإعدادات (`Settings`) عبر `setting_key`.
- **الخارجيّةُ** (هل المزوّدُ مُهيَّأ؟) — من فاحصاتِ الاتصال/الحالةِ القائمة (`Integrations`/`Health`/
  `PushService`/`MobilePlatform`) — تُقرأ لا تُكرَّر.
