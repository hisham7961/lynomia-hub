# البوّابةُ الزمنيّةُ الآمنة (04)

> القدراتُ **الاختياريّةُ** وحدَها تُبوَّب زمنيّاً، عبر بوّابةٍ مركزيّةٍ واحدة، **مستقلّةٍ عن
> الصلاحية**. لا `if(feature())` متناثرٌ في التطبيق.

## البوّابة المركزيّة

`hub_capability(string $key): bool` — تعيد «أمتاحةٌ القدرة؟». قدرةٌ غيرُ مسجَّلةٍ ⇒ `true` (لا
نكسر ما ليس تحت السجلّ). الثوابتُ النظاميّةُ متاحةٌ دائماً. الاختياريّةُ المُطفأةُ ⇒ `false`.

**فحصان مستقلّان، كلاهما يجب أن يمرّ:**

```
القدرةُ متاحةٌ؟  (hub_capability)      ← التوافر
المستخدمُ مصرَّحٌ له؟ (hub_can/الحرّاس)  ← الصلاحية
```

## الفشلُ الآمن (المُطبَّق على presence/typing)

عند إطفاءِ قدرةٍ اختياريّة، مسارُها **يفشل بأمان** في كلِّ سطح:

| السطح | السلوك عند الإطفاء |
|---|---|
| مسارٌ مباشر (POST typing ويباً وجوالاً) | ٤٠٤ |
| بياناتُ الاستجابة (typing في `since`) | مصفوفةٌ فارغة — لا تسريب |
| الحضور (`DmController::presence`) | `[]` مركزيّاً — لا حضورَ في أيِّ سطح |
| البحثُ/الإقلاعُ/لوحةُ الأوامر | لا تظهر (لا رابطَ نشط) |
| العميل | محجوبٌ أصلاً (البوّابة) |

**لا يُعتمَد على إخفاءِ الواجهةِ حاجزاً:** الحجبُ خادميٌّ (٤٠٤/قصرُ البيانات)، والإخفاءُ عرضيٌّ فوقه.

## حفظُ السلوكِ القائم (§12)

الرايتان تفتراضِ «مُفعَّل» (غيابُ الرايةِ = ENABLED)، فإدخالُ السجلِّ **لا يُطفئ شيئاً**؛
الاختباراتُ القائمةُ خضراءُ بلا تغيير. الإطفاءُ فعلٌ صريحٌ من المالكِ وحدَه.
